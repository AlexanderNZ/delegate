## Report

When you finish, write one JSON object to `<STATE>/runs/<RUN>/reports/c.fixup-2.specialist.json`. Give each field the JSON type that this list names. The engine rejects a report with a field of a different type.

Required fields:

- `ticket`: string
- `status`: string, one of `committed`, `blocked`, `partial`
- `branch`: string
- `head_sha`: string
- `commits`: list of strings
- `gates_green`: boolean
- `summary`: string

Optional fields:

- `worktree`: string
- `blocked_reason`: string
- `judgement_calls`: string

`gates_green` states whether the tests that you ran pass. The engine does not trust this field: the result of the gates that the engine runs decides. A string field holds one string. To give more than one item in a string field, join the items with "; ".

Example:

```json
{
  "ticket": "c",
  "status": "committed",
  "branch": "<the branch of the worktree>",
  "head_sha": "<the full SHA of the tip of the branch>",
  "commits": [
    "<the full SHA of the first commit that you added>",
    "<the full SHA of the next commit>"
  ],
  "gates_green": true,
  "summary": "<what you changed, in one or two sentences>",
  "worktree": "<STATE>/worktrees/<RUN>/c",
  "judgement_calls": "<the first decision that you made>; <the next decision>"
}
```
