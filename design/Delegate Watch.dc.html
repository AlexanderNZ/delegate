Proposed: delegate runs
Not in the repo yet: the run index and the runs command do not exist, and the command names are provisional. delegate runs lists every run of the run index, on every host, and reads each run's snapshot from its host; --timeline is its second view. Sample: now 14:20, trend window the last 6h. Combined numbers: progress is tickets ended over tickets total across reachable runs that have not ended; the ETA is the latest ETA, with the count of runs that have none; time is wall clock; an unreachable run and an ended run are out of every sum. Columns hold one kind of value each: slip is how much later the ETA is than it read 2h ago, from 30m (provisional); alert is blank when nothing is wrong; do is the short name of the command to run. New glyphs: the sparkline ▁▂▃▄▅▆▇ (dim; tickets ended in a cell, scaled to the largest; ASCII .:-=+*#) and the now column ┊ (now; ASCII :). In --timeline, ─ is the life of a run, ● a ticket that ended built, ░ the projection to the ETA.
